# Arpit | Portfolio Website

Official motion graphics, SaaS animation, and video editing portfolio of **Arpit**.

## ✦ Features
- **Hero Showcase:** High-impact hero visual with interactive cosmic particles, 3D tilt card, and live studio badge.
- **Interactive Rope Trigger:** Pull rope interaction to reveal Arpit's profile dossier.
- **Projects Showcase:** Motion graphics, SaaS UI animations, viral reels, gaming edits, and talking head editing.
- **Interactive Modals:** Project lightbox view and direct contact inquiry modals.

## ✦ Built With
- Semantic HTML5
- Vanilla CSS3 (Custom animations & particle system)
- Modern JavaScript (ES6+)
